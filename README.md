<h1 align="center">Greedy Search Algorithm Practice</h1>

<p align="center">
A simple Python program for practicing greedy graph search.
</p>

<hr/>

<h2>📝 Description</h2>
This demonstrates a greedy search algorithm on a weighted graph in Python.  
Starting from a node, the algorithm selects the adjacent unvisited node with the smallest edge weight and continues until it reaches a terminal node.  
It records the path and the total cost.
